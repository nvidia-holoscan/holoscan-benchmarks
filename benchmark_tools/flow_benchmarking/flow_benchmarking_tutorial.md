# Flow benchmarking tutorial

The Holoscan SDK 5.0.0 tutorial is now part of the [flow tracking guide](README.md).
Start with its [build-and-run example](README.md#quick-start), then follow
[application instrumentation](README.md#benchmark-your-own-application).

The former Holoscan SDK 1–4 tutorial used source patching, `Application.track()`, and
scheduler replacement. Those instructions do not apply to Holoscan SDK 5's Graph API.
Legacy log analysis and historical CSV plotting are still supported.
